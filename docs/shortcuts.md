# Keyboard shortcuts

On macOS, use Cmd wherever this page says Ctrl, and Option wherever it says Alt. The menus show
each shortcut beside its command.

## Anywhere in the window

| Shortcut | Command |
|---|---|
| **Ctrl+N** | New project |
| **Ctrl+O** | Open projects (the launcher) |
| **Ctrl+S** | Save the project |
| **Ctrl+Q** | Quit |
| **Ctrl+,** | Settings |
| **Ctrl+1** | Table view |
| **Ctrl+2** | Gallery view |
| **Ctrl+B** | Toggle the left dock |
| **Ctrl+Alt+B** | Toggle the right dock |
| **``Ctrl+` ``** | Toggle the bottom dock |
| **Ctrl+Shift+M** | Toggle the Problems panel |
| **Shift+Esc** | Zoom the focused panel to fill the window, or return it to its place |

## In the table and gallery

| Shortcut | Command |
|---|---|
| **Ctrl+F** | Find in table |
| **Ctrl+H** | Replace in table |
| **Esc** | Drop the selection |

## In the grid

These act on the selected cells or rows while the grid has focus. While you edit a cell, the
same keys edit its text instead.

| Shortcut | Command |
|---|---|
| **Enter** | Edit the selected cell |
| **Delete** or **Backspace** | Clear the selected cells |
| **Ctrl+X**, **Ctrl+C**, **Ctrl+V** | Cut, copy, paste |
| **Ctrl+Z** | Undo |
| **Ctrl+Shift+Z** or **Ctrl+Y** | Redo |
| **Alt+Shift+Up** | Insert a row above |
| **Alt+Shift+Down** | Insert a row below |
| **Ctrl+-** | Delete the row |
| **Ctrl+]** | Indent the row |
| **Ctrl+[** | Outdent the row |
| **Ctrl+Alt+Right** | Expand all rows |
| **Ctrl+Alt+Left** | Collapse all rows |
| **Shift+F2** | Add a note to the cell |

Undo, redo, and **Esc** also work in the Details panel, which edits the same grid.

## In the file viewer

| Shortcut | Command |
|---|---|
| **Esc** | Close the fullscreen viewer |

See [The grid](grid.md) for what each command does, and [Projects](projects.md#saving) for
how saving works.
