qrate — Pop-out Viewer window

A second window that shows the selected row's file at full size, with the row's fields beside it. It follows the table selection, so on two monitors the table sits on one screen and the scan fills the other. Chrome, sidebar and pills use theme tokens. NEW marks new UI, TO CHECK marks copy or behaviour I guessed. Tweaks switch Light/Dark and the stage background.

  • Stage: the file sits on the viewer's own backdrop (black 85% over background), so the pop-out looks like the full-screen viewer and a photo is never shown on white. Title bar and sidebar follow the theme. Switch the tweak to "Theme stage" to compare muted.background.
  • Sidebar: right side, 320px by default, drag 240–720px, collapsed with the title bar's panel button (same icon as the main window). It holds Details without the image pane.
  • Find: for documents the sidebar gets a Details | Find tab strip, and Ctrl+F switches to Find. This keeps the window to two columns at 800px wide. Esc returns to Details, then does nothing further (the pop-out has no overlay to close).
  • Following: the title bar's left side has the follow toggle, ▲▼ and "Row 42 of 318". ↑/↓ and ▲▼ move the table selection too, so both windows always agree unless pinned.

Lucide app-window at 16px, placed second in the action chip after Maximize, since both open a larger view. One pop-out per project: when it is open the button stays highlighted and clicking it focuses the existing window.
