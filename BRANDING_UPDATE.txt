# qRate Branding Update - Archival Workspace Focus

Updated qRate from a generic "high-performance CSV editor" to a purpose-built "Digital Archival Workspace" focused on cultural heritage cataloging.

- Problem/solution framework for archivists

- Standards support: RAD, MODS, LCSH, TGM

## Messaging Framework

### Primary Message
qRate eliminates technical bottlenecks in archival workflows by treating metadata as databases, not text files.

### Target Audience
1. Small archives with limited resources
2. Major institutions with massive collections
3. Volunteer digitization projects
4. Graduate archival programs
5. Cultural heritage professionals

### Key Differentiators
1. **Standards-First**: RAD, MODS, LCSH native support
2. **Local-First**: Data sovereignty, no cloud dependencies
3. **Human-in-the-Loop AI**: Augments, doesn't replace expertise
4. **Crash-Proof**: ACID transactions protect cultural memory
5. **Open Formats**: CSV/SQLite for long-term sustainability

## Marketing Implications

### Elevator Pitch (Before)
"A high-performance CSV editor that loads gigabyte files instantly using SQLite."

### Elevator Pitch (After)
"A digital archival workspace that eliminates the technical bottlenecks in cultural heritage cataloging—instant loading, crash-proof editing, and AI-assisted metadata creation."

### Key Benefits (Archivist-Focused)
1. Stop fighting with Excel crashes
2. Process collections 10x faster
3. Never lose work to software failures
4. Validate against archival standards
5. Work with AI assistance, not replacement

### Competitive Positioning
- **vs Excel**: Doesn't crash, standards-aware, purpose-built
- **vs Cloud Tools**: Local-first, data sovereignty, works offline
- **vs Generic Editors**: Archival standards, validation, AI integration
- **vs Proprietary Software**: Open-source, open formats, no vendor lock-in
