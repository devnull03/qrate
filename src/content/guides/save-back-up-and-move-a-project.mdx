A catalogue is months of work. This last tutorial covers the three things that keep it safe:
knowing when qrate has saved, knowing what to back up, and moving a project without breaking it.

## How qrate saves

qrate saves on its own. A moment after you stop typing, it writes your edits to the project file
in the background, so a big project never makes you wait. Column settings and layout save the
moment you change them.

- A **dot in the title bar** means there are edits it has not written yet.
- **Ctrl+S** saves at once, whatever the autosave setting.
- If a save fails, say the drive is full, qrate tells you and keeps your changes. It never drops
  edits without asking you first.

To change this, open **Settings ▸ Table ▸ Saving**: turn **Autosave** off, or choose **On every
edit** instead of **After a short pause**.

## What to back up

A project is two things in two places:

- **The `.qrate` file** holds every row, column setting, note and the full change history. It is
  one file. Copy it, and you have copied the project.
- **The files folder** holds your scans. qrate only links to them, so they are not inside the
  `.qrate` file and need backing up on their own.

Copy the `.qrate` file while qrate is closed, or right after a save, so you catch everything.

## Mark a version before a big change

Before a bulk find-and-replace or handing the project to a colleague, name a point in the history.
In the **History** panel, right-click the latest saved change, choose **Name This Version…**, and
type something like "Before subject clean-up". If it goes wrong, right-click that change and choose
**Restore Project to Here…**. The restore is itself a change you can undo, and no history is
deleted.

## Move a project to another computer

1. Copy the `.qrate` file and the files folder to the new computer or drive.
2. Open the `.qrate` file in qrate.
3. If the files folder is in a new place, qrate notices. Instead of hundreds of missing-file
   errors, it shows one banner above the grid.

4. Click **Relink…** and pick the folder's new location. qrate counts the files it can find there
   first and asks you to confirm, so you never relink to the wrong folder by accident.

If you picked a folder one level off, qrate also looks in its parent and sibling folders and offers
the one holding the most files. [Relink scans after the files folder moved](/guides/relink-scans-after-the-folder-moved)
covers the trickier cases.

## Hand the project to someone without qrate

Not everyone you work with will install qrate. **File ▸ Export** writes CSV, Excel, JSON-LD and a
ZIP of data plus files. The [online converter](/convert) turns a `.qrate` file into CSV, Excel,
JSON-LD, CSL-JSON or a Google Sheet in any browser. See [Open a .qrate file without installing qrate](/guides/open-a-qrate-file-without-qrate).
